# Roadmap

The current focus is a dependable native import → edit → preview → save → export workflow. Feature status is tracked in docs/feature-status.md.

Next work covers richer media caches, streaming decode, GPU texture sharing and larger desktop workflow regressions. Further milestones cover transforms/crop, effect chains and keyframes, titles, transitions, workspace docking, proxy media, SQLite indexing, JavaScript extensions and plugin hosting.

Release qualification requires long and variable-rate media, device-loss recovery, memory/performance profiling, clean-machine tests, installers, accessibility review and complete redistribution source/notices for dependency binaries.
