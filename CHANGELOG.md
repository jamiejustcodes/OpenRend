# Changelog

## 0.1.0 — in development

- Added the .NET 10 WPF desktop workspace and C++20 media engine.
- Added frame-based tracks, trimming, splitting, snapping and transactional undo/redo.
- Added linked picture/sound groups and independent groups after splitting.
- Added hardware/WARP timeline compositing with deterministic CPU fallback.
- Added real media metadata, thumbnails, sampled waveforms and preview decoding.
- Added shared timeline rendering, clip opacity/fades and stereo audio mixing.
- Added H.264/AAC timeline export, progress, cancellation and destination preservation.
- Added atomic JSON projects, autosave recovery, relinking and legacy edit-decision import.
- Added managed/native tests using generated media and real encoded output.
- Added UI Automation selection/track controls, keyboard navigation and a complete desktop export regression.
- Refined the compact workspace, original vector toolbars, track headers, master meters and persistent panel sizing.
- Added grouped cut/copy/paste across project frame rates, media filters, preview guides, zoom and snapshots.
- Corrected maximized work-area bounds and retained-frame repainting after preview exposure.
- Preserved delayed stream starts, variable frame intervals, resampler tails and display rotation.
- Added track opacity, gain and stereo balance with undo, persistence, accessible sliders and shared preview/export processing.
