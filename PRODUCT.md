# OpenRend

OpenRend is a free, open source Windows nonlinear video editor for local video and audio workflows. The application uses C#/.NET 10, WPF and a C++20 media engine. Project files hold non-destructive edit decisions and references to source media.

The primary workflow is import, arrange and trim multiple tracks, preview, save and export the edited timeline. Source files remain untouched. A dense desktop workspace, keyboard editing, visible frame boundaries and consistent preview/export decisions are product requirements.

The intended license is GPL-3.0-or-later. Capabilities and verification status must describe implemented behavior accurately.
