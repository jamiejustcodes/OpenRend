# Feature status

Status applies to OpenRend's own implementation and stated test cases. It does not establish exhaustive behavior or performance across all media.

| Area | Status | Evidence / limits |
| --- | --- | --- |
| Rational project frame grid | Tested | Long frame roundtrip and integer boundaries in core tests |
| Placement, move, trim, split | Tested | Domain tests; splits preserve fade envelopes |
| Default Dissolve / crossfades | Partial, tested locally | Paired source alpha, CPU/D3D and encoded output, split/save/clipboard preservation, cut-to-overlap and whole-frame overlap-to-cut conversion, strip properties, plug-in removal, saved browser favorites, move/trim alignment and automatic placement with same-track ripple. Explicit finite-video Loop/Hold modes support source extensions; audio looping, odd centered cuts, event locks, broader catalog, progress curves and complete properties/browser UI remain open. See [implementation progress](implementation-progress.md). |
| Video source modes | Partial, tested locally | Switches > Loop selects source repetition or last-frame hold for finite video. Continuous rational source phase, negative loop offsets, trim/split/clipboard/save/undo, CPU/D3D/encoded output and desktop workflow are checked. Legacy events remain bounded; audio looping, default-loop preferences, fractional-frame mode changes and arbitrary duration/VFR parity remain limited. |
| Undo/redo and locks | Tested | Validation failures roll back, redo branches reset |
| Mute, solo, visibility | Tested | Shared evaluator and real media export tests |
| JSON projects, autosave, relink | Tested | Relative paths, concurrent reader snapshots, ordered save requests, blocked-save preservation, source overwrite rejection and unknown-version rejection |
| Legacy project import | Tested | Read-only conversion with ordering/audio/fade/group preservation |
| Linked groups | Tested | Atomic move/trim/split/delete, independent split groups, locked-member rollback |
| Cut / copy / paste | Tested | Group identity remapping, cross-project media and frame-rate conversion, source-end rounding, undo and locked-cut failure |
| FFmpeg decode and seek | Tested | Native tests, real H.264/FFV1/audio, UTF-8 paths and still frame retention |
| Stream timing / orientation | Tested | Delayed audio/video, nonzero origin, VFR holds, resampler EOF drain and quarter-turn matrices |
| Thumbnails / waveform peaks | Implemented | Source decoding; waveform is bounded sampled windows |
| Multitrack preview / export | Tested | Real trim/offset/split/opacity/mute/mix encoded output; ffprobe frame count |
| Render templates / ranges | Tested | Vegas Pro 1:1 render catalog (MAGIX AVC/AAC MP4, MAGIX HEVC/AAC MP4, Apple ProRes MOV, Sony Wave Audio WAV, MP3 Audio), property search, format filtering, match project settings, saved favorites, channel remapping (Mono, Swap, Mute L/R), stretch to fill, integrated LUFS and true peak loudness logging (.loudness.log), loop selection by ruler or I/O, encoded frame/sample checks at integer and rational rates, dynamic file size and disk space estimates, and desktop export. See [rendering](rendering.md). |
| D3D11 preview / D3D11VA decode | Tested locally | Actual hardware device/decoder verified on development machine; CPU transfer remains |
| GPU timeline compositing | Tested locally | Hardware and WARP match CPU within one byte per channel; upload/readback remains |
| WASAPI synchronized playback | Tested locally | Real output clock seek/pause/drain, underrun accounting and loopback tone verification |
| WPF desktop editing | Tested locally | Native preview pixels advance during playback and restore on Stop; edge hover/held resize cursor, outside-edge trim, Escape cancellation, selection/track states/split/undo/redo/save/reopen/export and ffprobe validation |
| Timeline accessibility | Tested | SelectionItem and Invoke/Toggle providers, track/clip keyboard navigation |
| Timeline event to Trimmer | Tested locally | Open in Trimmer loads the file-backed source of a forward, unretimed event and sets the cursor and selection from its trimmed source range. The command is unavailable for generated sources and ranges that extend outside the file. |
| Trimmer playback | Tested locally | Source video follows the rational project frame rate. Source audio uses the shared WASAPI playback engine, and the Trimmer cursor follows its device clock. The desktop workflow verifies a one-second selection at 60 fps and a handoff from Trimmer audio to timeline seek. WASAPI loopback verifies a marked audio range beyond a silent lead-in. |
| Trimmer stream placement | Tested locally | The Video and Audio buttons drag the marked range to compatible tracks. I and O mark the source range. A starts at the timeline cursor and Shift+A ends there, on the focused compatible track when available. Shift+A keeps the source Out point when the placement reaches project start. The desktop workflow verifies both stream drops and both keyboard placements in the saved project. |
| Project Media sources | Tested locally | Thumbnails show source duration, dimensions, frame rate and measured audio channel count. Replace source file and opening-time relink preserve event ranges and media IDs. The desktop relink workflow recovered mono audio metadata and preserved the saved edit. |
| Explorer source preview | Tested locally | Auto-play selection uses the shared render engine and monitor gain, without importing the source. The desktop workflow measures rendered preview pixels and confirms that toggling Auto-play off restores the timeline view. |
| Event buttons and options | Tested locally | Pan/Crop, video FX and overflow actions target the clicked event; locked/narrow/clipped cases, accessible actions after zoom/scroll/resize, and session-only header/name/length options |
| Track opacity / gain / pan | Tested | Atomic level edits, lock checks, accessible range sliders and actual encoded pixels/stereo samples. The timeline audio gain control runs from silence to +6 dB. Pan snaps to center. Saved gains above the current fader range retain their value until adjusted. |
| Automation point drags | Tested locally | Event and track point drags preview the curve and commit once on release. Moving a point retains its curve. Escape cancels the preview. The desktop track workflow verifies save, undo, redo and cancellation. |
| Track heights | Tested locally | The track header's Track height menu minimizes, expands or restores each track for the current project session. Event geometry, selection, envelope editing and accessibility use the visible row heights. |
| Timeline loop playback | Tested locally | Q repeats the selected frame range, or the whole project if no range is selected. The preview follows the looped audio clock on one WASAPI stream. The desktop and fractional-rate WASAPI loopback tests cover repeated wraps. |
| Master Bus meters | Tested locally | Stereo sample peaks with one-second hold, per-channel overload indicators, momentary, short-term and gated integrated LUFS, and true peak from the 48 kHz mix before final clipping and monitor gain. The desktop workflow reads all three loudness values, checks live Dim and Mute, and retains the integrated result on stop. |
| Preview display controls | Tested | Monitor zoom, safe-area overlay and drop-frame timecode; snapshots use project-resolution render |
| Event Pan/Crop | Tested locally | Source-pixel rectangle, rotation/pivot, aspect lock, interactive workspace and six temporal curves with right-click/keyboard selection; integer-frame dragging/retiming and collision preservation, persistence, trim/split/clipboard continuity, GPU/CPU comparison and actual encoded output |
| Pan/Crop presets | Tested locally | Type a name to save a crop position preset, then choose it from the same field to apply it. Presets are available after restart. Deleting a saved preset leaves the current event crop in place. |
| Workspace layouts | Partial, tested locally | Core tools can float, dock in Tools or Preview, or create one resizable upper group. Trimmer also floats and can dock beside Video Preview in Source Window Layout. Five presets and custom layouts preserve dock groups, active tabs, splitter sizes, visibility and floating bounds. Desktop workflows passed at 96 and 120 DPI. A live scale change kept the editor and floating Trimmer in the work area. Physical display removal and moves between displays with different scale factors remain unverified. |
| Workspace status bar | Tested locally | Cursor timecode and ruler settings, selection duration, project dimensions and frame rate, and available space on the project drive. Untitled projects show space on the recovery drive. |
| Tool and dialog title bars | Tested locally | Standard Windows captions use the shared OpenRend colors and retain system buttons. Live captures verified the caption color in Marker, Region, Pan/Crop and Render As. Windows contrast themes use system caption colors. |
| Shared tab layout | Tested locally | Project Properties shows tabs above its fields, and workspace tabs appear below their panes. The desktop tests check both positions, settings navigation, docking, and render settings. |
| Details tables | Tested locally | Edit Details, Project Media Details and Organize Layouts share column and row styling. The desktop workflow resizes and reorders Edit Details columns, double-clicks an event row to seek, and verifies Project Media Details still shows its source. |
| Edit Details sorting and time display | Tested locally | Columns sort by the underlying frame or playback rate where applicable. The sort survives filtering, and copying follows the visible row order. Time displays use the current project ruler. Marker and region color names match the picker. |
| Timeline transport | Tested locally | Space stops at the starting cursor, Enter pauses at the current frame, Home/End seek project bounds and Page Up/Down scroll one viewport. Timeline arrows step frames, Shift+Arrow steps one project second and Ctrl+Arrow selects adjacent clips. |
| Timeline shuttle | Tested locally | J and L step through 1×, 2×, 4×, 8× and 16× in either direction. K pauses. Holding K with J or L plays at quarter speed until release. Playback resamples the shared timeline mix and follows the WASAPI clock. |
| Timeline scrub | Tested locally | Drag the playhead to seek in whole project frames. Pointer motion produces short, variable-rate cues from the shared timeline mix. Letting go stops the scrub session. |
| Timeline markers and regions | Tested locally | M adds a numbered marker. R creates a region from the current range. Double-click a region bar to restore its selection. Both edit forms share the editor layout and named color swatches. Marker label and color share one undo step, and the region form validates bounds inline. The desktop workflow verifies saved labels, color and bounds. |
| Auto Ripple ruler and automation edits | Tested locally | Ctrl+L toggles Auto Ripple. All modes ripple envelopes on affected tracks. Both ruler-aware modes also adjust regions and markers during move, trim, delete, paste and Trimmer insertion. A region that spans an edit follows the changed portion of its range. Desktop moves verify saved region and envelope positions for All Tracks and Affected Tracks. |
| Split, slip and slide | Tested locally | S splits selected events or the event at the cursor on the focused track. Alt-drag slips the source within fixed event boundaries. Ctrl+Alt-drag on the event body slides its boundaries over the same timeline-aligned source. Ctrl+Shift+U toggles grouping for edits. Slide supports forward normal-speed audio and constant-rate video on aligned source frame grids. |
| Event snap offset | Tested locally | Drag the marker at the bottom of an event to set its snap offset. Release commits one undoable edit and updates the active take. Escape cancels the drag. The desktop workflow verifies the saved event and take offsets after drag, undo, redo and cancellation. |
| Timeline snapping | Tested locally | F8 or N toggles snapping. Hold Shift during a move or edge trim to reverse the setting for that drag. The ten-DIP threshold includes event edges, the cursor, markers and region endpoints. The desktop workflow checks a region-end trim at two zoom levels and both Shift overrides. |
| Timeline edit dialogs | Tested locally | Set Time at Cursor, Insert Time and Paste Repeat use the same compact form layout, keyboard focus and inline validation. The desktop workflow checks the ruler offset, cancellation and exact saved insertion and repeat positions. |
| Editor menu access keys | Tested locally | Edit and Options support keyboard mnemonics. Ruler choices use one project edit from the Options menu, timecode or timeline ruler and support undo and redo. The desktop workflow opens Paste Repeat and saves a ruler format using the menu access keys. |
| Event video effects | Tested | 63 parameterized built-ins (including 9 AI effects and an imported 3D LUT); bypass, locks, undo/redo, independent split state, version-6 persistence, deterministic noise/grain, alpha-safe filtering, CPU/D3D comparison and encoded export. See the [supported catalog](video-effects.md). |
| Startup project creation | Partial, tested locally | Welcome New/Open/Getting Started pages, five aspect ratios × three resolutions, rational rate choices, recent projects and startup preference. Desktop portrait creation/save/reopen verified. Full advanced settings and exact visual comparison remain open. See [project startup](project-startup.md). |
| Video FX chooser | Tested locally | Category/search filters and staged Add/Replace/Remove; Cancel isolation and accepted chain as one undo step |
| AI Tools (TTS, STT, Auto Reframe) | Tested locally | AI Text to Speech (Ctrl+Shift+P) with Kokoro/StyleTTS/SAPI voice models and timeline/media pool placement; AI Speech to Text with subtitle transcription, find/replace, SubRip (.srt) export and Subtitles from Speech track; AI Auto Reframe with 9:16/1:1/4:5/4:3/16:9/2.4:1 presets, subject tracking and smooth Pan/Crop keyframes |
| Text-Based Editing | Tested locally | The Selected events filter follows timeline selection. Find next moves through matching words and wraps. Edit Word uses the shared form. The desktop workflow verifies that typing in Find leaves the timeline intact and that a word edit preserves its frame position. |
| Effects | Partial | Opacity, gain, pan, fades, animated crop and built-in video FX; effect keyframes, spatial spline smoothing, masks and titles pending |
| Proxies, advanced cache, scripting, plugin hosting | Planned | No placeholder UI controls |
| Broad media/performance qualification | Pending | No professional-scale throughput or full format coverage claim |
