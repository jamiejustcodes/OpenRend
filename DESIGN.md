# Desktop workspace

Mode: Operate. A compact editing desk for sustained work on Windows. The preview and timeline receive most of the available space; controls use familiar desktop conventions.

Palette: window #141414, panel #262626, timeline #1E1E1E, divider #111111, text #E8E8E8, secondary #B8B8B8, selection #438AC8. Video clips use muted blue and audio clips muted green. Selection is reinforced with an outline.

Segoe UI at 11 px serves controls and the ruler. The main timeline timecode uses Segoe UI at 20 px; transport timecodes use Consolas. Controls are compact, square edged, with visible hover, disabled and keyboard focus states.

The title and menu share a 32 px row, followed by a 34 px file toolbar. The upper workspace is initially 600 px high. It places bottom-tabbed media tools on the left, an initially 844 px video preview on the center/right, and a 122 px master meter on the far right. The media panel absorbs window width changes. Resizable dividers adjust these dimensions. The timeline spans the width below; track headers are 256 px wide within the 4 px window margin, the ruler is 46 px high, tracks start at 69 px high, and transport controls sit beneath a horizontal scrollbar. Default time zoom is 13.4 px per second.

The timeline paints time, clips, real waveforms and the playhead. Dragging a clip moves it; dragging an edge trims it. The ruler seeks; the mouse wheel scrolls and Ctrl+wheel zooms. Context menus and keyboard shortcuts expose the same editing actions.
